# ForecastIQ results

This directory contains lightweight manifests, diagnostics, and reproducible summaries. Generated checkpoints, local machine paths, caches, and large training outputs should remain outside Git.

`nhits_e2e/summary.csv` is the compact five-series integration result. `nhits_e2e/details.json` contains validation evidence and may include local artifact paths when regenerated; review and sanitize it before publication. Historical manifests preserve experiment hashes and should not be edited to fabricate portability.
